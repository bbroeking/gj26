# Approved gameplay concept index

These screens bind composition, readability, palette, scale, camera, and UI
hierarchy. They are not literal asset-count promises.

| Concept | Player state | Current use |
|---|---|---|
| `wayfinder-state-01-arrival.png` | First arrival in the growing yard | Reference when town legibility or physical growth is the leading weakness |
| `wayfinder-state-02-first-hollow.png` | First satisfying authored Hollow | Reference for camera aperture, combat readability, encounter scale, and `0.1.2-readable-hollow` |
| `wayfinder-state-03-hearth-giant.png` | Developed high-pressure road | Reference only when late encounter presentation becomes the leading weakness |

Each director cycle starts from the rendered game. A concept is consulted when
the leading gap is visual; the comparison chooses one bounded checkpoint rather
than reopening the full art direction.
