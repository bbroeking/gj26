How to use this

Tiles below open either a bespoke page or the markdown viewer (any doc in the corpus, rendered in-style with working wikilinks). Served locally — from the project root run python3 -m http.server 8765 and open http://127.0.0.1:8765/docs/. The viewer needs the server; opening via file:// won't fetch.
