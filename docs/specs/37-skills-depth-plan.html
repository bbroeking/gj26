Skills depth — the New World model

Vertical depth + active-channel gathering, built as one framework then three skills. Four reviewable goals.

The model you chose

Keep all 10 skills (honor the consolidation). Deliver the earned-mastery feeling through New World's vertical depth: luck-as-one-additive-number, tier-up refine rolls, tool-as-perk-container, and a hold-to-channel gather loop with an XP burst + occasional surprise. Drop everything MMO-economy (territories, trading post, the 0–250 grind, a separate Engineering skill) — collapse onto your existing 3-tier ladder.

Dependency order

The framework is the engine; the three skills are content that plugs into it. Build 37a first — the rest are parallel-able after.

Goal 37a — The Framework — the shared depth engine, no skill content

37a Gathering depth framework build first · blocks b/c/d

Seven reusable systems every gathering skill plugs into. Zero skill-specific content lives here — only the engine. When this lands, "add a new tiered node with luck + yield" is a data edit, not a code change.

1Active-channel gather loop

Replace instant pick / chop / mine with hold-to-gather: press → progress bar fills over channelTime → completes → drop + XP burst. Moving away cancels. This is the moment-to-moment feel you picked.

Formula
channelTime = node.baseTime / tool.gatherSpeed — tool tier speeds it up, node tier slows it down
New file
src/game/gathering.js (the action engine) + wiring in src/main.js interact branch
AcceptHolding on a tree fills a bar (~1.5s), pops logs + an XP float; walking away mid-channel cancels with no reward.

2Per-skill Luck — one additive number

The headline lever. Luck is a single number per skill, fed additively by skill level (free baseline) + tool luck-perks + food luck-buff. Rare drops sit above a roll threshold; more luck = more rares. Skill level is the cheapest feeder, so leveling literally improves your drop table.

Formula
luck(skill) = baseLuck(lv) + Σ toolLuckPerks + foodLuckBuff; pools are independent per skill (wilds-luck ≠ earth-luck)
New file
src/game/luck.js — luck() + rollDrops(node, luck)
Scaling
collapse NW's 100k-die to a readable 0–1 roll; rare thresholds tuned so a maxed skill alone gives a modest rare rate, food/tools push it higher
AcceptAt Wilds 1 a rare forageable never drops; at Wilds 35 it drops occasionally; with a luck-food active, noticeably more often.

3Tools as perk containers

Tools gain a tier (1–3) and slot perks across three axes: speed / luck / yield. Higher tier = faster channel + more perk slots. Tool-crafting folds into Earth (no separate Engineering skill — explicit research "drop").

Data
extend src/data/items.js tool entries: { tier, gatherSpeed, perks:[{axis,value}] }
Axes
speed → channel time · luck → feeds system 2 · yield → feeds system 5
AcceptA tier-2 pickaxe visibly gathers faster than tier-1; equipping one with a luck perk raises earth-luck.

4Node tiers + biome clustering

Nodes gain a tier, skill-gated for access and soft-gated by tool speed (a low tool is so slow it's effectively a wall). Nodes cluster by biome — where you are determines what you gather; the map becomes the tech tree. Collapse NW's 8 tiers onto your existing 3-tier ladder.

Data
extend spawn defs in src/scene/world.js (forageSpawns, trees, oreNodes) with tier + gate
Gates
tier 1 / 2 / 3 ≈ skill 1 / 15 / 30 (mirrors the Brindle/Bogiron/Cinderbloom ladder already in Earth)
AcceptA tier-3 node shows "needs Wilds 30 (you have M)" on hover and resists a tier-1 tool's channel.

5Yield + bonus-resource roll

The "2 instead of 1" surprise. Two layers: a flat yield-perk bump (tool), and a bonus-resource roll off the same luck pool as system 2 — a high roll pops an extra unit or a tier-up material on top of the base drop.

Where
drop-resolution in gathering.js — yield perk adds count; luck roll adds the surprise
AcceptHigh-level + high-luck gathers visibly produce doubles sometimes, with a distinct "+1!" float.

6Refining tier-up roll

Turns refining (smelt / smith / cook) from a deterministic button-press into a slot machine. On each refine, roll for bonus output and a chance the output rolls up a tier.

Formula
NW's Skill÷10 → 20% @ lv200, rescaled to our 99-cap: bonusChance = min(0.25, lv × 0.0025) → ~25% at 99
Where
smelt/smith/cook recipe resolution in src/main.js
AcceptSmelting at Earth 50 occasionally yields a bonus bar; rarely, a higher-tier bar's worth.

7Timed-buff plumbing

Generic timed buffs on the player — recovery (HoT), attribute (+stat for a duration), trade-skill (gathering-luck). Cook (37d) produces the foods; the framework owns the plumbing because attribute buffs touch combat stats and luck-food feeds system 2.

New file
src/game/buffs.js — apply / tick / expire + a HUD indicator
AcceptApplying a test luck-buff raises wilds-luck for its duration, shows a HUD timer, then expires cleanly.

+Gather/track split (the cheap evocative unlock)

You can harvest a tier before you can reliably find it. Rare nodes (Foxfire) don't show on any sense until a higher "track" milestone — so the grind between gather-level and track-level is rewarded by discovery, not just XP. Reuses your existing milestone slots (12/25/35).

AcceptChannel-gather a tier-2 herb; a rare pops occasionally via luck; the track unlock reveals rare nodes you previously had to stumble onto.

Goal 37d — Cook — the buff system, biggest opportunity

37dCook: recipes → timed buffsafter 37a · best with 37b

Cook currently only heals. New World's cooking is the connective tissue that makes gathering purposeful: gather → cook a buff food → buff improves combat or your next gather run → repeat. This is the loop that ties the whole skill arc together.

+Recipe shape & the three food categories

Recipe = one tier-locked primary (a tier-3 dish needs a tier-3 primary, no substituting down) + a flexible secondary (any item in category). Keep burn-chance as the low-level mechanic; add the system-6 yield roll at higher levels.

Review flow

Each goal is a self-contained reviewable unit. The handoff for each:

  1. You approve / amend a goal here.
  2. I write its spec — docs/specs/37a-framework.md, then 37b / 37c / 37d — capturing the resolved scope, grounded in 37-skill-depth-research.md.
  3. You review the spec.
  4. /spec implements it; an implementation -notes.md records decisions, deviations, and surprises.

Recommended start: approve 37a (the framework) — it's the foundation the three skills plug into, and nothing else can land cleanly until the channel loop + luck + buff plumbing exist. The three skills can then go in any order (Wilds is the biggest visible payoff; Earth is the smallest lift).
