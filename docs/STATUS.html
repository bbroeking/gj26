How to play

godot --path wyrd          # launches the game (Metal/Forward+, saves normally)

Keys: WASD move· 1–4/F skills· E interact· Q quaff· G grab· I pack· M satchel· K trades· Space roll· Esc the Lantern (co-op)· F10 sound (off by default)

The loop: gather herbs/ore/logs → mix inks & inscribe a chart at the bench (its affixes shape the run) → socket it at the Waystone → delve the seeded dungeon (combat, elites, a boss) → return with loot + XP → level your Wayfinding trade & spend a mastery pick → repeat, up to the level-17 cap and the Summit.

Co-op in 20 seconds

Host: Esc → The Lantern → "Light a fire" → "Copy address" → send it to a friend. They Esc → paste → "Join." Same network or Tailscale; port 7777. Full guide: docs/COOP.md.

How co-op works (short version)

  • Listen-server / peer-to-peer. The host's game is the server (authoritative); friends connect directly over ENet. Tailscale/LAN is just the network path — there's no cloud backend.
  • Deterministic shared runs. Socketing a chart sends only the seed; every machine rebuilds the identical dungeon locally. No level streaming.
  • Host owns fairness (enemy AI, damage, loot rolls); guests replay visuals (arrows, numbers, boss telegraphs, status). Each player keeps their own satchel/gold/trades.
