# 0015 — Asset attribution & in-game credits

**Status:** accepted (2026-06-18)

## Context

Wayfinder is built with generative tools — code/design with **Claude**
(Anthropic), 3D models via **Meshy**, concept art via **Midjourney**, and
sound/music via **ElevenLabs** — on the **Godot 4.6** engine. Distributing the
game on any platform makes attribution both a courtesy and, for some of these
services' license terms, an obligation. Until now there was no in-game credits
surface and no single record of what was generated by what.

## Decision

Ship an in-game **Credits** screen (reachable from the title menu,
`scripts/ui/credits_menu.gd`) that names the engine and each generative tool,
and keep this ADR as the canonical attribution record. Before any public
release, re-check each tool's current license/attribution terms against this
list and update both surfaces.

Tools, as of this ADR:

| Area | Tool |
|------|------|
| Design & code | Claude (Anthropic) |
| 3D models | Meshy |
| Concept art | Midjourney |
| Sound & music | ElevenLabs |
| Engine | Godot 4.6 |

## Consequences

- The credits screen must stay in sync with the toolchain — add a tool here and
  to `credits_menu.gd` when it's introduced.
- No license has been chosen for the project yet (README: "all rights reserved
  for now"); that decision is separate and still open.
