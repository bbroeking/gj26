# Wayfinder Knowledge Base — agent instructions

This is an LLM Wiki over the design of **Wayfinder**. The full schema —
directory layout, page conventions, and the ingest/query/lint workflows —
lives in [`CLAUDE.md`](CLAUDE.md). **Read it before doing anything here.**

In short: you own and maintain every page under `wiki/`; the human reads it in
Obsidian and directs the work. Raw sources are the game repo's own `../docs/`,
`../docs/specs/`, `../docs/adr/`, `../CONTEXT.md`, and `../wyrd/` code — read-only,
in place. Pattern reference: [`LLM-WIKI-PATTERN.md`](LLM-WIKI-PATTERN.md).
